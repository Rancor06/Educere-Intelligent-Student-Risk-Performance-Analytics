# Day 49 — Connected Student Risk-Analysis Database Workflow

## Overview

Day 49 extended the EduTrack student-management system by connecting the machine-learning prediction workflow with the student database.

Instead of treating the ML prediction as a temporary API response, the system now stores the prediction information alongside the corresponding student record in MySQL.

The workflow is:

```text
Student Data
    ↓
React Frontend
    ↓
Flask API
    ↓
ML Prediction Model
    ↓
Risk Analysis
    ↓
MySQL Student Record
```

---

## Objectives

The main objectives of Day 49 were:

- Connect ML prediction results with student records.
- Extend the student database schema to store risk-analysis information.
- Persist prediction results in MySQL.
- Store prediction confidence and class probabilities.
- Store the input values used for prediction.
- Record when the risk analysis was performed.
- Maintain the existing student-management functionality.
- Keep the ML workflow connected to the deployed backend.

---

## Database Changes

The existing `students` table was extended to support persistent ML risk-analysis information.

A dedicated migration file was added:

```text
backend/migration_day49_student_risk_analysis.sql
```

The migration adds the following fields:

| Field | Purpose |
|---|---|
| `risk_prediction` | Stores the predicted student outcome |
| `risk_confidence` | Stores the confidence associated with the prediction |
| `risk_probabilities` | Stores probability information for the available prediction classes |
| `prediction_inputs` | Stores the input data used by the ML model |
| `risk_analyzed_at` | Stores the date/time of the risk analysis |

The database therefore stores both the student's regular information and the result of the ML-based risk analysis.

---

## Risk-Analysis Workflow

The completed workflow operates as follows:

```text
Student Information
        ↓
Student Record
        ↓
Prediction Input
        ↓
Flask /api/predict
        ↓
Decision Tree Model
        ↓
Prediction
        ↓
Confidence + Probabilities
        ↓
Student Risk Fields
        ↓
MySQL
```

The prediction result is no longer limited to the response displayed by the frontend.

The relevant prediction information can be associated with the student's database record for later retrieval.

---

## Stored Prediction Information

### Prediction

The predicted class is stored in:

```text
risk_prediction
```

For example:

```text
Dropout
```

### Confidence

The model confidence is stored in:

```text
risk_confidence
```

### Probabilities

The probability distribution for the available classes is stored in:

```text
risk_probabilities
```

### Prediction Inputs

The values supplied to the ML model are stored in:

```text
prediction_inputs
```

This provides a record of the information used when the prediction was generated.

### Analysis Timestamp

The time at which the analysis was performed is stored in:

```text
risk_analyzed_at
```
